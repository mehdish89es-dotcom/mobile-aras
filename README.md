# موبایل ارس — نسخه نهایی آنلاین

این پروژه یک وب‌اپ/PWA حرفه‌ای برای اطلاع‌رسانی قیمت موبایل است و **فروش، سبد خرید و پرداخت ندارد**.

## اتصال قیمت
Backend هر ۵ دقیقه صفحات قیمت mobile.ir را برای سه گروه Samsung، Xiaomi و iPhone دریافت می‌کند، مدل و قیمت را نرمال می‌کند و در `/api/prices` به اپ می‌دهد. خود اپ نیز هر ۶۰ ثانیه وضعیت را بررسی می‌کند. دکمه «بروزرسانی» دریافت فوری را درخواست می‌کند.

mobile.ir اعلام می‌کند قیمت‌ها مستقیماً توسط فروشگاه‌ها درج می‌شوند و اختلاف‌ها می‌تواند ناشی از گارانتی، رنگ و حافظه باشد؛ بنابراین اپ باید «منبع» و زمان دریافت را نمایش دهد.

**نکته حقوقی/فنی:** پیش از استفاده تجاری، شرایط استفاده و محدودیت‌های منبع را بررسی کنید. اگر mobile.ir API یا فید رسمی در اختیار شما قرار دهد، تابع `update()` را به API رسمی تغییر دهید؛ این روش پایدارتر از HTML parsing است.

## اجرای روی کامپیوتر/سرور
1. Node.js 20 نصب باشد.
2. در پوشه پروژه: `npm install`
3. سپس: `npm start`
4. مرورگر: `http://localhost:3000`

## آنلاین کردن
پروژه برای سرویس‌های Node مانند Render آماده است. `render.yaml` و `Dockerfile` دارد. بعد از Deploy یک آدرس HTTPS می‌گیرید.

## نصب روی گوشی Android بدون Play Store
بعد از آنلاین شدن:
1. آدرس HTTPS برنامه را با Chrome باز کنید.
2. منوی سه‌نقطه Chrome را بزنید.
3. «Add to Home screen / افزودن به صفحه اصلی» یا «Install app» را انتخاب کنید.
4. آیکن «موبایل ارس» روی صفحه اصلی اضافه می‌شود و مانند اپ باز می‌شود.

## APK
این نسخه عمداً به شکل PWA آماده شده تا قیمت‌ها بدون انتشار APK جدید از سرور بروزرسانی شوند. اگر APK لازم است، همین URL HTTPS را با Android WebView/Trusted Web Activity بسته‌بندی کنید؛ APK فقط پوسته اپ خواهد بود و داده‌ها از Backend زنده می‌آیند.

## ساختار
- `public/index.html` رابط کاربری
- `server.js` اتصال و کش قیمت
- `manifest.webmanifest` نصب PWA
- `sw.js` کش رابط
- `render.yaml` تنظیم استقرار Render
- `Dockerfile` استقرار Docker
